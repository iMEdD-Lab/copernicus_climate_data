## Copernicus climate data
This repo contains two files that were used for the visualization and analysis of data from Copernicus. 
1. index.html: contains the plotly visualization that is embedded in the [article](https://lab.imedd.org/en/decades-of-climate-data-with-a-few-lines-of-code-analysing-copernicus-data/)
2. ERA5-visualization-pipeline.ipynb: contains the script that was used for the retrieval, analysis and visualization of the data.
